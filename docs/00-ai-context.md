# AI Development Context

This project is being built for the Studio Graphene Full Stack Developer assessment.

Goal:
Build a high-quality Expense Tracker demonstrating full-stack engineering skills.

Evaluation Priorities:

1. Code Quality (25%)
2. Functionality (25%)
3. Full Stack Integration (20%)
4. UI/UX (15%)
5. Documentation, Git & Deployment (10%)
6. Bonus (5%)

Important:

- Prioritize maintainability over feature quantity.
- Keep architecture simple.
- Avoid over-engineering.
- Every piece of code should be easy to explain during interview.

Approved Stack:

Frontend:
- React
- Vite
- Tailwind CSS
- Axios
- Recharts

Backend:
- Node.js
- Express

Storage:
- JSON file persistence

Testing:
- Vitest or Jest

Do NOT use:

- Redux
- GraphQL
- MongoDB
- PostgreSQL
- Docker
- Microservices

Architecture:

Client
→ API Layer
→ Controller
→ Service
→ Storage Layer

Coding Rules:

- Functional components only
- Hooks only
- Small reusable functions
- Proper error handling
- Input validation everywhere
- Meaningful variable names
- Consistent folder structure

Project Goal:

Deliver all Must Have requirements,
all Should Have requirements,
JSON persistence,
and at least one meaningful backend test.

The codebase must feel like a production-ready junior developer project.
